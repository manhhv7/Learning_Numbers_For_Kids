# Bé vui học số — PWA miễn phí

## Đưa lên GitHub Pages
1. Tạo repository **public** mới trên GitHub, ví dụ `be-vui-hoc-so`.
2. Upload toàn bộ **7 file** trong thư mục này vào thư mục gốc của repository (không upload file ZIP).
3. Vào **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Chọn branch `main`, thư mục `/(root)` và bấm **Save**.
5. Đợi GitHub Pages xuất bản rồi mở đường dẫn Pages mà GitHub cung cấp.

## Cài trên iPad
1. Mở URL Pages bằng **Safari**.
2. Bấm **Chia sẻ (Share)** → **Thêm vào Màn hình chính (Add to Home Screen)** → **Thêm**.
3. Mở biểu tượng **Bé học số** trên màn hình chính.
4. Sau khi mở trực tuyến ít nhất một lần để tải cache, ứng dụng có thể chạy offline. Giọng đọc phụ thuộc giọng tiếng Việt được cài trên iPad và có thể khác nhau theo thiết bị.

## Lưu ý
- Không dùng backend, không quảng cáo, không có phí sử dụng game.
- Điểm sao lưu bằng localStorage trên thiết bị; có thể mất nếu xóa dữ liệu website.
- Luyện viết chỉ xác nhận có nét vẽ, chưa chấm độ chính xác hình dạng.
- Mã nguồn được tự xây dựng, không sử dụng hình ảnh hoặc âm thanh độc quyền của ứng dụng tham khảo.
